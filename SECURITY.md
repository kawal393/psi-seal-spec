# Security and Verify-the-Verifier

This verifier is MIT. Audit every line.

## Reporting a divergence

If you find any input for which `hello_psi.py` and `hello-psi.js` disagree, or
any divergence from the live canonical schema at
https://ai-governance-standard.com/.well-known/psi-schema.json :

1. Open an issue with the exact input and both outputs.
2. You are credited here, permanently, unless you ask not to be.
3. The fix is merged into the record with a changelog entry.

The math must survive its maker.
